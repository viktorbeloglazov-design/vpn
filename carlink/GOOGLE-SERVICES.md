# Настоящий Android Auto на телефоне без сервисов Google

Пошагово, для Samsung серии W (китайская прошивка) и Porsche Taycan с PCM 6.0.
После этого в машине появляется штатный Android Auto — тот самый, с картами и
музыкой на экране PCM. Приложение CarLink для такой связки больше не нужно: оно
остаётся диагностикой и стендом.

Почему без этого никак — раздел 1 в [README](README.md): машина проверяет, что
сертификат телефона подписан Google, а такой сертификат есть только у самих
сервисов Google Play.

---

## Что ставим

Четыре пакета. Имена настоящие, их же показывает `adb shell pm list packages`:

| Пакет | Что это | Обязателен |
|---|---|---|
| `com.google.android.gsf` | Google Services Framework | да, первым |
| `com.google.android.gms` | Google Play services | да, вторым |
| `com.android.vending` | Play Маркет | да, третьим |
| `com.google.android.projection.gearhead` | Android Auto | да, из Play Маркета |
| `com.google.android.googlequicksearchbox` | приложение Google | по желанию, для голосового помощника |

**Как выбрать нужный файл.** У каждого пакета десятки сборок. Подходит та, что
совпадает с телефоном по трём признакам:

- процессор — `arm64-v8a`;
- Android — версия телефона или ниже;
- экран — `nodpi` (подходит любому).

Точные значения для вашего телефона печатает первый же шаг ниже. Play services
раздаются набором файлов (`base` плюс `split`) — обычно это один архив `.apkm`
или `.xapk`; скрипт такой набор ставит сам.

Качать имеет смысл только там, где выложены неизменённые файлы с подписью Google
и эту подпись видно на странице загрузки. Обычное место — APKMirror. Сверяйте,
что имя пакета совпадает с таблицей выше: подделки отличаются именно им.

## Шаги

### 0. Подготовка

На телефоне: «Настройки» → «Сведения о телефоне» → семь раз нажать «Номер
сборки» → вернуться → «Параметры разработчика» → включить «Отладка по USB».
Подключить телефон к компьютеру и подтвердить запрос на экране.

### 1. Посмотреть, что уже есть

```bash
./scripts/carlink-gms.sh check
```

Печатает процессор, версию Android, плотность экрана и список того, что стоит, а
чего нет. С этими тремя значениями и идёте качать.

### 2. Скачать пакеты в одну папку

Например в `~/Downloads/gms`. Имена файлов менять не нужно — скрипт разбирает
порядок установки по ним.

### 3. Поставить

```bash
./scripts/carlink-gms.sh install ~/Downloads/gms
```

Ставит по порядку: framework, сервисы, Маркет. Наборы `.apkm`/`.xapk`
распаковывает и ставит одной командой, как и положено split-пакетам.

### 4. Перезагрузить

```bash
adb reboot
```

Без перезагрузки сервисы не поднимутся.

### 5. Войти в аккаунт

Открыть Play Маркет, войти в свой аккаунт Google.

### 6. Проверить сертификацию

Play Маркет → «Настройки» → «О приложении» → **«Сертификация Play Protect»**.

- «Устройство сертифицировано» — переходите к шагу 8.
- «Устройство не сертифицировано» — шаг 7.

### 7. Зарегистрировать телефон (если не сертифицирован)

```bash
./scripts/carlink-gms.sh id
```

Скрипт покажет номер устройства. Тот же номер показывает и само приложение
CarLink на главном экране — там есть кнопка «Скопировать номер».

Дальше: открыть <https://www.google.com/android/uncertified/>, войти **тем же**
аккаунтом, вставить номер, зарегистрировать. Подождать 10–20 минут, затем:

«Настройки» → «Приложения» → Play Маркет → «Хранилище» → «Очистить данные», то
же для «Сервисы Google Play», и перезагрузить телефон. После этого сертификация
обычно появляется.

### 8. Поставить Android Auto

Из Play Маркета, пакет `com.google.android.projection.gearhead`. В приложении
CarLink для этого есть кнопка — она открывает нужную страницу Маркета.

### 9. Включить запуск по проводу

Открыть Android Auto → «Настройки» → десять раз нажать на строку с версией →
согласиться на режим разработчика → включить **«Запускать Android Auto по
USB»**.

### 10. Подключить к машине

Кабель — оригинальный, с передачей данных, в порт USB-C в подлокотнике (тот, что
помечен значком данных, а не молнией). В PCM выбрать Android Auto, на телефоне
подтвердить запрос.

Проверить, что машина вообще переводит телефон в нужный режим:

```bash
./scripts/carlink-gms.sh check      # что стоит на телефоне
./scripts/carlink-diag.sh           # что происходит на проводе
```

## Если не получается

**Сертификация не появляется.** Повторите очистку данных Play Маркета и сервисов
Google Play, перезагрузитесь, подождите. Иногда регистрация доходит через час.

**В Galaxy Store есть «谷歌安装器» (Google Installer).** На части китайских
прошивок Samsung он ставит весь набор сам — это то же самое, что шаги 2–4, но
без компьютера. Если он есть, начните с него.

**Play Маркет не открывается или вылетает.** Обычно это несовпадение версии
сервисов с версией Android: возьмите сборку Play services для своей версии
Android, не более новую.

**Android Auto ставится, но не запускается в машине.** Проверьте шаг 9 и кабель.
Порт зарядки без данных — самая частая причина.

**Ничего не помогло.** Остаются пути B и C из [README](README.md): отдельный
дешёвый Android с сервисами Google в подлокотнике или CarLink как диагностика и
стенд.

---

## Когда всё заработало

У Google есть свой стенд головного устройства — Desktop Head Unit (DHU) из
Android SDK. Он работает в паре со штатным Android Auto и пригодится, если
захотите смотреть, как ведёт себя телефон, не садясь в машину.
