# QP VPN для Windows — установка

Для Windows 10 (сборка 1709 и новее) и Windows 11, 64 бита.

---

## 1. Скачать и распаковать

Ссылка (не меняется, всегда свежая версия):
**https://github.com/viktorbeloglazov-design/vpn/releases/download/latest/QPVPN-windows.zip**

Или наведите камеру телефона на картинку **QR-скачать-приложение.png**
из этой папки и перешлите ссылку себе.

1. Скачайте архив и распакуйте его в любую папку — например, `C:\QPVPN`.
   Установщик не нужен.
2. Внутри должны лежать рядом три файла:
   - `QPVPN.exe` — само приложение
   - `qpvpn-tunnel.exe` — служба туннеля
   - `wintun.dll` — сетевой адаптер

> Windows иногда показывает синее окно **«Система Windows защитила ваш
> компьютер»**. Нажмите **«Подробнее» → «Выполнить в любом случае»**:
> программа подписана своим ключом, а не сертификатом Microsoft.

---

## 2. Запустить

Запустите **QPVPN.exe**. Windows спросит разрешение на изменения —
согласитесь. Без прав администратора система не создаёт службу туннеля
и не поднимает сетевой адаптер, это требование самой Windows.

---

## 3. Добавить ключ, который вам прислали

### Если прислали ссылку `vpn://…`

1. Скопируйте ссылку целиком.
2. В окне программы нажмите **«Вставить ключ vpn:// из буфера»**.

### Если прислали картинку с QR-кодом

1. Сохраните картинку на компьютер.
2. Нажмите **«Открыть файл .conf или картинку с QR-кодом»** и выберите её.
   Либо просто перетащите картинку в окно программы.

### Если прислали файл `.conf`

Та же кнопка **«Открыть файл…»** или перетаскивание в окно.

Под кнопками появится строка вида «Ключ загружен: AmneziaWG, сервер …» —
значит, всё принято.

---

## 4. Включить

1. Нажмите большую круглую кнопку.
2. Нажмите **«Проверить мой IP»** — должно показать Казахстан.

---

## 5. Два переключателя

**«Обход блокировок»** — главный, включён сразу. Через VPN идут только
сервисы, которые без него не работают: нейросети, соцсети, мессенджеры,
видео, рабочие программы — 244 сервиса. Всё остальное — банки, госуслуги,
маркетплейсы, любой российский сайт — идёт напрямую, на обычной скорости.

**«Рабочие ресурсы»** — включён: рабочие адреса компании идут через VPN,
выключен — напрямую.

Остальное спрятано в **«Расширенные настройки»**: три режима
маршрутизации, обход российской зоны, DNS из профиля.

---

## Если что-то не так

| Что видно | Что делать |
|---|---|
| «Служба туннеля не запустилась» | Проверьте, что все три файла лежат рядом и что программу запустили с правами администратора |
| Программа не запускается вовсе | Windows могла заблокировать архив: правой кнопкой по нему → «Свойства» → «Разблокировать» → распакуйте заново |
| Подключается и сразу отключается | Проверьте, что не запущен другой VPN (AmneziaVPN, WireGuard) — два туннеля сразу Windows не поднимает |
| Страна не Казахстан | Выключите и включите кнопку, затем нажмите «Проверить мой IP» ещё раз |
| Интернет пропал при включении | Выключите туннель кнопкой; напишите нам — пришлём другой ключ |

---

### Что делать, если нужен второй клиент

Наше приложение — не единственный вариант: ключ `vpn://` подходит и для
бесплатного **AmneziaVPN** (https://amnezia.org/ru/downloads). Это может
пригодиться, если на компьютере нет прав администратора для нашей службы.
