# QP VPN для Windows

Два файла и библиотека:

| Файл | Что делает |
|---|---|
| `QPVPN.exe` | окно программы: переключатели, ключ, проверка адреса |
| `qpvpn-tunnel.exe` | служба туннеля на библиотеке AmneziaWG |
| `wintun.dll` | сетевой адаптер Wintun, подписанный WireGuard LLC |

## Как это устроено

Windows не умеет «исключающие» маршруты, как и Android: туннелю отдаётся
список `AllowedIPs` — то, что должно идти через VPN. Поэтому режим
«всё, кроме правил» считается как дополнение: всё адресное пространство
минус исключённые подсети.

Само шифрование и маскировку делает библиотека
[amneziawg-windows](https://github.com/amnezia-vpn/amneziawg-windows)
(лицензия MIT). Обычный клиент WireGuard для Windows здесь не годится:
его разборщик настроек считает параметры маскировки `Jc`, `S1` и прочие
ошибкой и отказывается запускать туннель.

`qpvpn-tunnel.exe` умеет ровно четыре вещи:

```
/installtunnelservice <файл.conf>   создать службу и запустить
/uninstalltunnelservice <имя>       остановить и удалить
/status <имя>                       состояние и счётчики, строкой JSON
/tunnelservice <файл.conf>          точка входа службы, её вызывает Windows
```

Служба называется `AmneziaWGTunnel$qpvpn` и живёт только пока включён
туннель: при выключении она удаляется.

## Где лежат файлы

- настройки программы — `%LOCALAPPDATA%\QPVPN\settings.json`
- ключ доступа — `%PROGRAMDATA%\QPVPN\qpvpn.conf`, доступ к нему закрыт
  для всех, кроме администраторов и системы: внутри приватный ключ

## Сборка

Собирается в облаке рабочим процессом `.github/workflows/windows.yml`:
Go 1.25 для службы (без C-компилятора, `CGO_ENABLED=0`) и .NET 8 для окна.
Маршрутизация здесь своя, не как на других платформах: через VPN идёт
только то, что перечислено, а весь остальной трафик — мимо туннеля.
Списки лежат в `OneCZone.cs` (рабочая зона для 1С) и `VpnServices.cs`
(ChatGPT, Claude, WhatsApp, YouTube).
