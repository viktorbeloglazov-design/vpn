# Сервер в Казахстане

Страна, которую видят сайты, определяется не приложением, а IP-адресом сервера.
Поэтому нужен VPS, физически размещённый в Казахстане, с казахстанским IP.

## Выбор хостинга

| Хостер | Где | Ориентир по цене |
|---|---|---|
| ps.kz | Алматы | от ~2 500 ₸/мес |
| hoster.kz | Алматы, Астана | от ~2 000 ₸/мес |
| ucloud.kz | Алматы | от ~3 000 ₸/мес |
| freehost.kz | Алматы | от ~2 500 ₸/мес |

Требования к тарифу — минимальные: 1 vCPU, 1 ГБ RAM, Ubuntu 22.04 или 24.04.
WireGuard почти не нагружает процессор, упор идёт в канал. Берите тариф с
безлимитным или большим трафиком, если планируете смотреть видео.

Проверьте перед оплатой, что IP действительно казахстанский:
`https://ipinfo.io/<IP>` должен показывать `KZ`.

Альтернатива своему серверу — готовый коммерческий VPN с локацией Казахстан,
который выдаёт конфиг WireGuard. Такой конфиг вставляется в приложение так же,
через «Вставить конфиг WireGuard…».

## Установка WireGuard

На сервере, под root:

```bash
# скопировать скрипт
scp server/install-wg-kz.sh root@ВАШ_СЕРВЕР:/root/
scp server/add-client.sh    root@ВАШ_СЕРВЕР:/root/

ssh root@ВАШ_СЕРВЕР
bash /root/install-wg-kz.sh --client mac
```

Скрипт:

1. ставит `wireguard`, `iptables`, `qrencode`;
2. включает форвардинг пакетов (`net.ipv4.ip_forward`);
3. создаёт `/etc/wireguard/wg0.conf` с NAT на внешний интерфейс и подсетью
   `10.8.0.0/24`, порт по умолчанию `51820/udp`;
4. включает автозапуск `wg-quick@wg0`;
5. заводит клиента и печатает готовый конфиг.

Порт можно сменить: `bash install-wg-kz.sh --port 51821`.

## Добавить ещё устройство

```bash
ssh root@ВАШ_СЕРВЕР 'bash /root/add-client.sh iphone'
```

Для телефона удобно использовать QR-код, который печатает скрипт, — его читает
официальное приложение WireGuard.

## Много устройств сразу (например, 40)

Один конфиг WireGuard рассчитан на одно устройство: пара ключей привязана к
одному адресу в туннеле, и сервер отвечает туда, откуда пришло последнее
рукопожатие. Поставите один файл на 40 телефонов — они будут по очереди выбивать
друг друга из туннеля. Рабочих подходов два.

**Пачка отдельных клиентов** — каждому устройству свой ключ и свой адрес:

```bash
scp server/add-clients-bulk.sh root@ВАШ_СЕРВЕР:/root/
ssh root@ВАШ_СЕРВЕР 'bash /root/add-clients-bulk.sh 40'
ssh root@ВАШ_СЕРВЕР 'bash /root/add-clients-bulk.sh 40 --prefix office --qr'
```

Скрипт заводит клиентов `device-01 … device-40`, дописывает их в `wg0.conf`,
применяет изменения через `wg syncconf` (уже поднятые туннели не рвутся) и
складывает конфиги в `/etc/wireguard/clients/<имя>/<имя>.conf` с правами `0600`.
Повторный запуск ничего не дублирует: существующие клиенты остаются со своими
ключами и адресами. Флаг `--qr` печатает QR-коды для телефонов.

В подсети `10.8.0.0/24` помещается 253 клиента; если нужно больше, расширьте её
в `wg0.conf` до `/23`. И прикиньте канал: 40 активных устройств с видео — это
десятки Мбит/с.

**Один туннель на роутере** — конфиг ставится в Keenetic, MikroTik, OpenWrt или
GL.iNet, и вся сеть за роутером выходит через него по NAT. Для сервера это
по-прежнему один клиент, добавлять пиров не нужно. Минус: скорость делится на
всех, а устройства вне этой сети не покрыты.

## Срок действия ключей

Ключи WireGuard бессрочные — в протоколе нет ни даты истечения, ни отзыва по
времени. Пара ключей работает, пока её `[Peer]` стоит в `/etc/wireguard/wg0.conf`.
Чтобы список клиентов не терялся:

- держите `SaveConfig = false` (так его и создаёт `install-wg-kz.sh`) — иначе при
  остановке службы файл перезаписывается состоянием из памяти;
- пиры добавляйте в `wg0.conf`, а не только командой `wg set`: заданные через
  `wg set` живут до перезагрузки;
- включите автозапуск: `systemctl enable wg-quick@wg0`.

Чтобы отобрать доступ у устройства, удалите его блок `[Peer]` из `wg0.conf` и
выполните `wg syncconf wg0 <(wg-quick strip wg0)`.

## Firewall

Откройте UDP-порт (по умолчанию 51820) в панели хостера и, если включён ufw:

```bash
ufw allow 51820/udp
ufw allow OpenSSH
ufw enable
```

## Проверка на сервере

```bash
wg show                     # есть ли handshake с вашим Mac
systemctl status wg-quick@wg0
journalctl -u wg-quick@wg0 -n 50
```

Если handshake нет — почти всегда закрыт UDP-порт или указан не тот
внешний IP в `Endpoint`.

## Безопасность

- Ключи клиентов лежат в `/etc/wireguard/clients/<имя>/` с правами `0700`.
- Не пересылайте `.conf` открытым каналом: в нём приватный ключ.
- Отозвать доступ: удалить блок `[Peer]` из `/etc/wireguard/wg0.conf` и
  выполнить `systemctl restart wg-quick@wg0`.
