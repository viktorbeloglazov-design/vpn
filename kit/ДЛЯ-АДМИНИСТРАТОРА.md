# Для администратора — как выдавать доступ

Этот файл не для пользователей: он про то, как выпускать ключи
и что кому отправлять. Из архива, который уходит человеку,
эту страницу лучше удалять.

---

## Что такое «QR-код» на самом деле

QR-код — это картинка, в которую зашита строка `vpn://…`.
В строке лежат сжатые настройки: адрес сервера, публичный ключ сервера,
**приватный ключ этого человека** и адрес внутри туннеля.

Отсюда три правила:

1. **Один человек — один ключ.** Не пересылайте один код двоим: два
   устройства с одним ключом мешают друг другу, соединение будет рваться.
2. **Ключ равен доступу.** Кто получил код — тот подключается. Пересылать
   его в общие чаты нельзя.
3. **Отозвать можно только на сервере** — удалив peer. Само приложение
   ничего не отзывает.

---

## Способ 1. У вас уже есть AmneziaVPN со своим сервером

1. Откройте AmneziaVPN на своём компьютере.
2. Выберите сервер → **«Поделиться»**.
3. Протокол — **AmneziaWG** (или WireGuard). Другие протоколы
   наши приложения не понимают, а AmneziaVPN у пользователя — понимает.
4. Выберите, кому: Amnezia создаст отдельный ключ и покажет
   **QR-код** и **ссылку**.
5. Картинку с кодом — на телефон, ссылку текстом — на компьютер.

---

## Способ 2. Свой сервер WireGuard в Казахстане

Разворачивается один раз скриптом из репозитория:

```bash
sudo bash server/install-wg-kz.sh
```

Дальше на каждого человека:

```bash
sudo bash server/add-client.sh ivanov-iphone
```

Скрипт напечатает готовый конфиг, покажет QR-код прямо в терминале
и сохранит картинку `/etc/wireguard/clients/ivanov-iphone/ivanov-iphone.png`.
Заберите картинку к себе и отправьте человеку:

```bash
scp root@АДРЕС-СЕРВЕРА:/etc/wireguard/clients/ivanov-iphone/ivanov-iphone.png .
```

Отключить человека: удалите его peer на сервере —
`wg set wg0 peer <ПУБЛИЧНЫЙ_КЛЮЧ> remove`, затем сохраните
конфигурацию `wg-quick save wg0`.

## Что отправлять человеку

| Устройство | Что ставит | Что отправить |
|---|---|---|
| Android | QP VPN (файл .apk из папки Android) | картинку с QR-кодом |
| Mac | QP VPN (файл .dmg из папки Mac) | картинку с QR-кодом или ссылку `vpn://` |
| Windows | AmneziaVPN | ссылку `vpn://` текстом |
| iPhone | DefaultVPN из App Store | картинку с QR-кодом |

Отправлять лучше двумя сообщениями: сначала папку с инструкцией,
потом ключ. Тогда ключ проще отозвать и переслать заново,
не пересобирая архив.

## Короткий текст для сообщения

> Держите доступ к VPN.
> 1. Возьмите из архива папку под своё устройство и откройте файл
>    КАК-УСТАНОВИТЬ — там по шагам.
> 2. Следом пришлю картинку с кодом: это ваш личный ключ,
>    он добавляется в приложение за одно действие.
> 3. Код личный, дальше не пересылайте.

## Почему на iPhone не AmneziaVPN

AmneziaVPN убран из российского App Store по требованию Роскомнадзора:
с российским Apple ID его не найти. **DefaultVPN** — приложение тех же
разработчиков, оно в российском магазине есть и принимает те же ключи
`vpn://` с AmneziaWG. Поэтому в инструкции для iPhone указан именно он.

## Что внутри у приложений

- Протокол: **AmneziaWG** (с маскировкой) и обычный **WireGuard**.
- В QP VPN для Android главный переключатель **«Обход блокировок»**
  включён сразу: через VPN идут 244 сервиса и 110 программ, которым
  нужен зарубежный адрес, всё остальное — напрямую. Российская зона
  (8 649 подсетей) идёт мимо туннеля.
- Второй переключатель **«Рабочие ресурсы»** заворачивает в туннель
  внутренние адреса компании.
