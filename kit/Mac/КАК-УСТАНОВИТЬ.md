# QP VPN для Mac — установка

Подходит для macOS 13 (Ventura) и новее. Один файл работает
и на Apple Silicon (M1–M4), и на Intel.

---

## 1. Установить приложение

### Способ А — одной командой (проще всего)

Откройте «Терминал» (Launchpad → наберите «Терминал») и вставьте строку:

```bash
curl -fsSL https://raw.githubusercontent.com/viktorbeloglazov-design/vpn/claude/mac-vpn-app-routes-7jv8o7/scripts/install-mac.sh | bash
```

Команда скачает свежую версию, положит её в «Программы» и откроет.
Скачанный так файл macOS не помечает как «загруженный из интернета»,
поэтому предупреждений о неизвестном разработчике не будет.

### Способ Б — из файла в этой папке

1. Откройте **QPVPN.dmg** двойным щелчком.
2. Перетащите **QPVPN** в папку **«Программы»**.
3. Откройте «Программы» и запустите QP VPN.
4. При первом запуске macOS скажет, что приложение не из App Store.
   Разрешите один раз:
   **«Готово» → Системные настройки → Конфиденциальность и безопасность →
   раздел «Безопасность» → «Открыть всё равно» → подтвердите паролем →
   «Открыть»**.

   На macOS Sequoia и новее правая кнопка → «Открыть» больше не помогает,
   нужен именно этот путь. Либо одна команда в «Терминале»:

   ```bash
   xattr -dr com.apple.quarantine /Applications/QPVPN.app
   ```

---

## 2. Установить служебную часть

В окне приложения нажмите **«Установить службу»** и введите пароль
администратора Mac. Это делается один раз: служба поднимает сам туннель,
приложение без неё только показывает настройки.

---

## 3. Добавить QR-код, который вам прислали

На компьютере камеру наводить не на что, поэтому QR-код добавляется
картинкой — приложение читает код с изображения.

### Если QR-код прислали картинкой

1. Сохраните картинку на Mac (перетащите из мессенджера на рабочий стол).
2. Откройте вкладку **«Сервер»**.
3. **«Открыть файл или QR-код…»** → выберите картинку.
   Либо просто перетащите картинку в пунктирную рамку в окне программы.

### Если QR-код скопировали как картинку

Вкладка **«Сервер» → «Вставить из буфера»**.

### Если прислали ссылку `vpn://…`

1. Скопируйте ссылку целиком.
2. Вкладка **«Сервер» → «Вставить из буфера»**.

### Если прислали файл `.conf`

Вкладка **«Сервер» → «Открыть файл или QR-код…»** → выберите файл,
либо перетащите файл в пунктирную рамку.

После этого поля «Endpoint», «Публичный ключ сервера» и адрес в туннеле
заполнятся сами — значит, ключ принят.

---

## 4. Включить

1. Вкладка **«Главное»** → круглая кнопка включения.
2. Нажмите **«Проверить мой IP»** — должно показать Казахстан.

Значок в строке меню наверху экрана показывает состояние и позволяет
включать и выключать VPN, не открывая окно.

---

## 5. Маршруты

Вкладка **«Маршруты»**: можно выбрать, что идёт через VPN, а что напрямую —
по доменам и по подсетям, с готовыми наборами (сервисы Казахстана,
банки и госуслуги РФ, маркетплейсы РФ, китайские поставщики).

---

## Если что-то не так

| Что видно | Что делать |
|---|---|
| «Файл "QPVPN" не был открыт» | Шаг 1, способ Б, пункт 4 |
| Значок прыгает в Dock и гаснет | Поставьте способом А — это снимает карантин macOS |
| «Установка не удалась» при установке службы | Запустите приложение из папки «Программы», а не из образа .dmg, и повторите |
| IP показывает не Казахстан | Выключите и включите кнопку; проверьте, что служба установлена |
