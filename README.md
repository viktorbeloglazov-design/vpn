# KZTunnel — VPN для Mac с выходом в Казахстане

Приложение для macOS: одна кнопка «включить/выключить» и настраиваемые маршруты —
вы сами решаете, что идёт через казахстанский VPN, а что напрямую.

```
┌──────────────────────────────────────────────────────────┐
│  (◉)  Подключён                     Время сессии  12 мин │
│       KZ-Алматы · 91.201.xx.xx:51820  Handshake  8 с наз │
│       [Всё через VPN, кроме правил]   Принято   412,3 МБ │
│       🌐 Проверить мой IP  →  91.201.xx.xx · 🇰🇿 KZ, Almaty│
├──────────────────────────────────────────────────────────┤
│  Маршруты │ Сервер │ Настройки                           │
└──────────────────────────────────────────────────────────┘
```

## Что умеет

- **Кнопка включения** в окне и в строке меню macOS.
- **Три режима маршрутизации**:
  - `Весь трафик через VPN` — казахстанский IP для всего;
  - `Только правила через VPN` — обычный интернет прямой, в туннель уходят лишь
    выбранные сайты и подсети;
  - `Всё через VPN, кроме правил` — казахстанский IP по умолчанию, а банки РФ,
    кабинеты маркетплейсов и китайские поставщики идут напрямую.
- **Правила по доменам и подсетям**. Домены автоматически пересчитываются в IP
  каждые несколько минут — если у сайта сменились адреса, маршруты обновятся сами.
- **Готовые наборы правил**: сервисы Казахстана, банки и госуслуги РФ,
  маркетплейсы РФ, китайские поставщики, локальная сеть, видеозвонки.
- **Проверка внешнего IP** прямо в окне — видно, из какой страны вас видят.
- **Защита от утечки IPv6**: пока VPN включён, IPv6 на сетевых службах отключается
  (возвращается при выключении).
- **Автопереподключение**, если сервер перестал отвечать.

## Из чего состоит

| Компонент | Назначение |
|---|---|
| `KZTunnel.app` | интерфейс: кнопка, маршруты, настройки. Работает от пользователя |
| `kztunneld` | служба под root (launchd): поднимает туннель, правит маршруты |
| `server/*.sh` | разворачивают WireGuard на вашем VPS в Казахстане |

Обмен между приложением и службой — через два файла в
`/Library/Application Support/KZTunnel`: приложение пишет `config.json`,
служба исполняет его и публикует `status.json`. Никаких сетевых портов
и привилегированных XPC-сервисов.

Под капотом — WireGuard (`wireguard-go` + `wg-quick`), самый быстрый и
предсказуемый вариант для Mac.

## Быстрый старт

### 1. Сервер в Казахстане

Нужен VPS у казахстанского хостера (ps.kz, hoster.kz, ucloud.kz, freehost.kz и т. п.)
— именно его IP будут видеть сайты. Подробности и выбор тарифа: [docs/SERVER.md](docs/SERVER.md).

```bash
# на сервере, под root
scp server/install-wg-kz.sh root@ВАШ_СЕРВЕР:/root/
ssh root@ВАШ_СЕРВЕР 'bash /root/install-wg-kz.sh --client mac'
```

Скрипт напечатает готовый клиентский конфиг — скопируйте его.

### 2. Зависимости на Mac

```bash
brew install wireguard-tools wireguard-go
```

### 3. Сборка и установка

```bash
git clone https://github.com/viktorbeloglazov-design/vpn.git
cd vpn
./scripts/build.sh          # соберёт dist/KZTunnel.app
sudo ./scripts/install.sh   # поставит службу kztunneld
open dist/KZTunnel.app
```

Подробности: [docs/BUILD.md](docs/BUILD.md).

### 4. Настройка

1. Вкладка **Сервер** → «Вставить конфиг WireGuard…» → вставьте текст из шага 1.
2. Вкладка **Маршруты** → выберите режим и при необходимости добавьте наборы правил.
3. Нажмите круглую кнопку включения.
4. Нажмите «Проверить мой IP» — должно появиться `🇰🇿 KZ`.

## Как выбрать режим

| Задача | Режим | Правила |
|---|---|---|
| Нужен казахстанский IP везде | Весь трафик через VPN | — |
| Нужен KZ только для пары сервисов | Только правила через VPN | домены этих сервисов |
| Нужен KZ по умолчанию, но банки РФ и кабинеты маркетплейсов должны видеть российский IP | Всё через VPN, кроме правил | наборы «Банки и госуслуги РФ», «Маркетплейсы РФ» |

Как именно работают маршруты и в чём ограничения доменных правил —
[docs/ROUTES.md](docs/ROUTES.md).

## Если что-то не работает

Смотрите [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) и журнал:

```bash
tail -f /var/log/kztunnel.log
```

## Ограничения

- Приложение подписано ad-hoc подписью (без платного Apple Developer Program).
  Для App Store и штатного NetworkExtension нужен платный аккаунт разработчика —
  здесь вместо него используется связка launchd-службы и `wireguard-go`.
- Маршрутизация «по приложениям» (например, «только Safari через VPN») в этой
  схеме невозможна — маршруты работают по адресам назначения.
- Нет kill switch: если туннель упадёт, трафик пойдёт напрямую (служба при этом
  сама попробует переподключиться).
- Файл `config.json` содержит приватный ключ WireGuard и доступен на чтение
  администраторам компьютера (группа `staff`).
