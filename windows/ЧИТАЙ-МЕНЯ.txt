QP VPN для Windows
Premium VPN · Special for Kupibas Group

1. Распакуйте эту папку целиком, например в C:\QPVPN.
   Все три файла должны лежать рядом:
     QPVPN.exe         — само приложение
     qpvpn-tunnel.exe  — служба туннеля
     wintun.dll        — сетевой адаптер

2. Запустите QPVPN.exe. Windows спросит разрешение на изменения —
   согласитесь: без прав администратора туннель не поднять.

3. Добавьте ключ, который вам прислали:
     ссылка vpn://  — кнопка «Вставить ключ vpn:// из буфера»
     QR-код         — кнопка «Открыть файл…», выберите картинку

4. Нажмите круглую кнопку, затем «Проверить мой IP».

Главный переключатель «Обход блокировок» включён сразу: через VPN идут
только сервисы, которым он нужен, а банки, госуслуги и российские сайты
работают напрямую, на обычной скорости.

Вопросы: пишите тому, кто прислал вам эту папку.
