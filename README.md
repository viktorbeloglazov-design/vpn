# QP VPN — свой VPN с выходом в Казахстане

Приложения для Mac, Android, Windows и iPhone. Одна кнопка «включить» — и всё,
что заблокировано, открывается, а российские сайты продолжают видеть российский
адрес. Настраивать маршруты не нужно: они зашиты в приложение.

| Платформа | Постоянная ссылка | Что нужно |
|---|---|---|
| macOS 13+ | [`QPVPN-mac.dmg`](https://github.com/viktorbeloglazov-design/vpn/releases/download/latest/QPVPN-mac.dmg) | перетащить в «Программы», нажать «Установить службу» |
| Android 8+ | [`QPVPN-android.apk`](https://github.com/viktorbeloglazov-design/vpn/releases/download/latest/QPVPN-android.apk) | открыть файл, разрешить установку |
| Windows 10/11 | [`QPVPN-windows.zip`](https://github.com/viktorbeloglazov-design/vpn/releases/download/latest/QPVPN-windows.zip) | распаковать, запустить от администратора |
| iPhone | собирается из исходников | нужен Apple Developer Program |

Ссылки не меняются от версии к версии: по ним всегда лежит свежая сборка.
Версия для Android описана отдельно: [docs/ANDROID.md](docs/ANDROID.md).

## Что умеет

- **Один переключатель** — «Рабочие ресурсы». Остальное зашито: заблокированные
  сервисы всегда идут через VPN, российская зона — всегда напрямую.
- **МАХ, госуслуги, банки и маркетплейсы работают при включённом VPN.** На
  Android приложения, которые ругаются на VPN, вдобавок пропускаются мимо
  туннеля целиком — им VPN не виден вообще.
- **Значок VPN в строке состояния** на Android и в строке меню на Mac.
- **Запасной вход.** Если до сервера не достучаться напрямую, приложение само
  пробует узел-пересыльщик. Ключ при этом тот же.
- **Подбор размера пакета (MTU).** В гостевых и мобильных сетях большие пакеты
  часто не проходят целиком: сообщения уходят, а видео крутится. Приложение
  проверяет это само и спускается по лесенке 1420 → 1380 → 1320 → 1280,
  подошедший размер запоминает.
- **Замер скорости** — приём и отдача, через VPN и мимо него, на одной закачке.
- **Автообновление** — см. следующий раздел.
- **Проверка внешнего IP** прямо в окне.
- **Автопереподключение**, если через туннель перестали идти данные.

## Обновление

Приложения ставятся файлом, мимо магазинов, — напомнить о новой версии некому.
Поэтому они смотрят сами: **раз в сутки при запуске**, по ссылке, которая не
меняется. Рядом со сборкой лежит файл с номером версии строкой
(`android-version.txt`, `mac-version.txt`, `windows-version.txt`) — читается
десяток байт вместо всей сборки.

Нашлась новая — в приложении появляется карточка с кнопкой «Обновить»:

- **Android** — скачивает `.apk` и отдаёт системному установщику;
- **Mac** — скачивает `.dmg` и открывает его в Finder;
- **Windows** — скачивает архив и показывает его в проводнике.

Ключ и настройки при обновлении остаются на месте. Спросить вручную, не дожидаясь
суток, можно в разделе «Ещё» (Mac, Android) или «Проверка» (Windows).

Версии сравниваются числами по частям: по буквам «1.2.10» оказалось бы меньше
«1.2.9», и десятую сборку человек бы не увидел.

## Из чего состоит

| Компонент | Назначение |
|---|---|
| `QPVPN.app` | Mac: интерфейс. Работает от пользователя |
| `kupibasvpnd` | Mac: служба под root (launchd): поднимает туннель, правит маршруты |
| `QPVPN.exe` + `qpvpn-tunnel.exe` | Windows: интерфейс и служба туннеля |
| `kz.qpvpn` | Android: VpnService внутри самого приложения |
| `server/*.sh` | разворачивают WireGuard на вашем VPS в Казахстане |

Обмен между приложением и службой на Mac — через два файла в
`/Library/Application Support/KupibasVPN`: приложение пишет `config.json`,
служба исполняет его и публикует `status.json`. Никаких сетевых портов
и привилегированных XPC-сервисов.

Под капотом — AmneziaWG и WireGuard.

## Установка на Mac одной командой

```bash
curl -fsSL https://raw.githubusercontent.com/viktorbeloglazov-design/vpn/claude/mac-vpn-app-routes-7jv8o7/scripts/install-mac.sh | bash
```

Скачает свежую сборку, поставит в «Программы» и откроет. Так надёжнее, чем
через браузер: файлы из браузера macOS помечает как «скачанные из интернета»,
и приложение без сертификата Apple за 99 долларов в год после первого отказа
перестаёт открываться совсем — значок прыгает в Dock и гаснет без сообщений.

## Скачать образ вручную

Свежий образ — на странице [релизов](https://github.com/viktorbeloglazov-design/vpn/releases).
Внутри один файл `KupibasVPN.dmg` для Apple Silicon и Intel сразу; всё нужное
для работы туннеля уже внутри приложения — Homebrew и терминал не нужны.

1. Откройте образ, перетащите `QPVPN.app` в «Программы».
2. Первый запуск macOS заблокирует: приложение подписано своим сертификатом.
   Разрешите его один раз — Системные настройки → Конфиденциальность и
   безопасность → «Открыть всё равно», либо командой
   `xattr -dr com.apple.quarantine /Applications/QPVPN.app`.
3. Нажмите «Установить службу» и введите пароль администратора.
4. Вкладка «Сервер» → «Вставить конфиг WireGuard…» → конфиг вашего сервера.

Дальше нужен сам сервер в Казахстане — о нём следующий раздел.

## Быстрый старт

### 1. Сервер в Казахстане

Нужен VPS у казахстанского хостера (ps.kz, hoster.kz, ucloud.kz, freehost.kz и т. п.)
— именно его IP будут видеть сайты. Подробности и выбор тарифа: [docs/SERVER.md](docs/SERVER.md).

```bash
# на сервере, под root
scp server/install-wg-kz.sh root@ВАШ_СЕРВЕР:/root/
ssh root@ВАШ_СЕРВЕР 'bash /root/install-wg-kz.sh --client mac'
```

Скрипт напечатает готовый клиентский конфиг — скопируйте его.

### 2. Зависимости на Mac

Нужны только для сборки из исходников — в готовом образе они уже внутри:

```bash
brew install wireguard-tools wireguard-go
```

### 3. Сборка и установка

```bash
git clone https://github.com/viktorbeloglazov-design/vpn.git
cd vpn
./scripts/build.sh          # соберёт dist/QPVPN.app
sudo ./scripts/install.sh   # поставит службу kupibasvpnd
open dist/QPVPN.app
```

Чтобы собрать такой же самодостаточный образ, как в релизах:

```bash
./scripts/ci/build-wireguard.sh /tmp/wg-tools       # утилиты WireGuard
./scripts/build.sh --universal --tools /tmp/wg-tools
./scripts/make-dmg.sh 1.0.0                          # dist/KupibasVPN-1.0.0.dmg
```

Подробности: [docs/BUILD.md](docs/BUILD.md).

### 4. Настройка

1. Вкладка **Сервер** → «Вставить конфиг WireGuard…» → вставьте текст из шага 1.
2. Нажмите круглую кнопку включения.
3. Нажмите «Проверить мой IP» — должно появиться `🇰🇿 KZ`.

## Как идут маршруты

Режимов и правил больше нет — выбирать нечего. Через VPN идёт всё, кроме
российской зоны: МАХ, госуслуги, банки и маркетплейсы работают напрямую и
российский адрес видят. Список российских подсетей укрупняется до размера,
который система прокладывает быстро, а сервисы, которые при укрупнении могли
бы уйти наружу, возвращаются в туннель поимённо.

Подробности и ограничения — [docs/ROUTES.md](docs/ROUTES.md).

## Если что-то не работает

Смотрите [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) и журнал:

```bash
tail -f /var/log/kupibas-vpn.log
```

## Ограничения

- Приложение подписано ad-hoc подписью (без платного Apple Developer Program).
  Для App Store и штатного NetworkExtension нужен платный аккаунт разработчика —
  здесь вместо него используется связка launchd-службы и `wireguard-go`.
- На Mac и Windows маршрутизация «по приложениям» невозможна — маршруты
  работают по адресам назначения. На Android она есть: приложения, которые
  ругаются на VPN, пропускаются мимо туннеля целиком.
- Нет kill switch: если туннель упадёт, трафик пойдёт напрямую (служба при этом
  сама попробует переподключиться).
- Файл `config.json` содержит приватный ключ WireGuard и доступен на чтение
  администраторам компьютера (группа `staff`).
