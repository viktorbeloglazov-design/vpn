# LiRus — русификация интерфейса Li Auto L9

Приложение для головного устройства Li Auto L9 (2023, Li OS на базе Android),
которое переводит интерфейс машины на русский язык.

Проект в начальной стадии: сейчас готов только **этап 0 — разведка**.
Архитектура приложения выбирается по тому, что покажет машина.

## Этап 0. Разведка

Нужно снять с машины отчёт о её возможностях. От него зависит всё остальное:
можно ли просто включить русскую локаль, можно ли подменить ресурсы системы,
или придётся переводить интерфейс на лету.

### Что понадобится

Ноутбук с `adb` (Android Debug Bridge) и кабель USB.

```bash
# macOS
brew install --cask android-platform-tools

# проверка
adb version
```

### Подключение к машине

**По кабелю.** Воткните USB в порт машины, который умеет передавать данные —
обычно это порт в центральном подлокотнике или под экраном, а не порт зарядки
в задней части салона. На экране машины подтвердите запрос «Разрешить отладку
по USB». Если запроса нет, отладку нужно включить в инженерном меню Li OS.

**По Wi-Fi.** Если отладка по сети уже включена, машина и ноутбук должны быть
в одной сети, а на машине открыт порт 5555. Адрес машины видно в настройках
Wi-Fi на её экране.

Проверка, что связь есть:

```bash
adb devices
```

Должна появиться строка с серийным номером и словом `device`.

### Запуск разведки

```bash
cd lirus/scripts
./probe.sh                    # по кабелю
./probe.sh 192.168.1.50       # по Wi-Fi, подставьте адрес машины
```

Скрипт **ничего не меняет** на машине — только читает. Проверки, которые
что-то записывают, выполняются лишь с флагом `--allow-changes`, и каждая
возвращает исходное значение обратно:

```bash
./probe.sh --allow-changes
```

Результат сохраняется в `scripts/probe_report.txt`. Пришлите этот файл целиком.

### Что собирается

| Раздел | Зачем |
|---|---|
| Устройство и система | версия Android, SDK, ABI, тип сборки — определяют minSdk и способ установки |
| Экраны | у L9 их несколько; оверлей нужно рисовать на каждом отдельно |
| Локали | есть ли в системе русский язык — тогда всё решается штатно |
| Root и права | возможна ли подмена ресурсов системы |
| Установка приложений | разрешена ли установка сторонних APK |
| Команды выдачи прав | получится ли настроить всё одной командой после установки |
| Accessibility и оверлеи | основа варианта с переводом на лету |
| Пакеты Li Auto | какие именно приложения предстоит переводить |

В конце скрипт сам выдаёт предварительный вердикт — какой из трёх вариантов
реализуем на вашей машине.

### Три возможные стратегии

**A. Штатная смена локали.** Если русский язык в системе есть, но скрыт в
интерфейсе, его достаточно включить и закрепить при загрузке. Самый надёжный
вариант: перевод делает сама система, ничего не рисуется поверх.

**B. Подмена ресурсов (RRO).** Если есть root или отладочная сборка, русские
строки подкладываются оверлеями ресурсов прямо в приложения Li Auto. Перевод
выглядит родным, не нагружает систему, но требует прав.

**C. Перевод на лету.** Служба доступности читает интерфейс, поверх китайского
текста рисуется русский. Работает без root на любой машине, но требует
аккуратности: нельзя перекрывать камеры, предупреждения и показания приборов.

Варианты можно сочетать: A или B там, где работают, C — для остального.

## Безопасность

Перевод интерфейса машины на ходу — вмешательство в то, что водитель видит
перед собой. В приложении заложены жёсткие ограничения: не перекрывать
предупреждения, камеры, приборную панель и окна систем помощи водителю;
оверлей не перехватывает касания; отключение одним движением.

Обновления Li Auto по воздуху могут менять интерфейс и сбрасывать настройки —
после каждого OTA разведку стоит прогнать заново.
