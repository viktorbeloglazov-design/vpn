# Версия для Android

Приложение QP VPN: тот же WireGuard-туннель и те же режимы маршрутизации, что в
версии для Mac, плюс маршрутизация по программам, которой на macOS нет.

## Установка

1. Скачайте `.apk` со страницы [релизов](https://github.com/viktorbeloglazov-design/vpn/releases)
   (тег вида `android-v1.0.0`) прямо на телефон.
2. Откройте файл. Android попросит разрешить установку из этого источника —
   это нормально для программы, которая ставится не через магазин.
3. При первом включении появится системное окно «Разрешить создавать
   VPN-подключение». Без него туннель поднять нельзя — так устроен Android.

Требуется Android 8.0 или новее. В пакете есть код для всех процессоров
(arm64, armeabi-v7a, x86, x86_64), так что подойдёт любой телефон и планшет.

## Настройка

1. Раздел **Профиль** → «Выбрать файл .conf» → конфиг вашего сервера в Казахстане.
   Файл можно открыть из «Загрузок», Google Диска, Telegram — откуда угодно,
   через обычное окно выбора файлов.
2. Раздел **Маршруты** → режим и правила.
3. Круглая кнопка на главной, затем «Проверить мой IP» — должно показать `KZ`.

## Чем отличается от версии для Mac

| Возможность | Mac | Android |
|---|---|---|
| Три режима маршрутизации | да | да |
| Правила по доменам и подсетям | да | да |
| Готовые наборы правил | да | да |
| Маршрутизация по программам | нет | **да** |
| Установка службы с паролем администратора | нужна | не нужна |
| Проверка внешнего адреса | да | да |

## Как это работает внутри

Android не умеет «исключающие» маршруты: системе передаётся один список того,
что заходит в туннель (AllowedIPs). Поэтому режим «всё кроме правил» считается
как **дополнение адресного пространства** — из `0.0.0.0/0` вычитаются
исключённые подсети, и получается минимальный набор маршрутов, покрывающий
всё остальное. Эта арифметика закрыта тестами (`android/app/src/test`).

Маршрутизация по программам — штатная возможность Android: выбранные пакеты
передаются туннелю как `IncludedApplications` или `ExcludedApplications`.
Список применяется при пересоздании туннеля, поэтому после правки приложение
на секунду переподключается.

Домены пересчитываются в адреса при подключении и далее по таймеру (по умолчанию
раз в 5 минут). Если адреса поменялись, маршруты обновляются без разрыва
соединения.

## Сборка из исходников

```bash
cd android
gradle test           # тесты арифметики подсетей и разбора конфига
gradle assembleRelease
# android/app/build/outputs/apk/release/app-release.apk
```

Нужны JDK 17 и Android SDK (platform 35, build-tools 35). Сборка подписывается
ключом `android/app/qpvpn-sideload.jks` — он лежит в репозитории осознанно:
приложение ставится файлом, а не через магазин, и этот ключ нужен только для
того, чтобы обновления вставали поверх прошлой версии, не стирая настройки.
Для публикации в Google Play понадобится собственный ключ.

## Ограничения

- Приложение не проходило проверку Google Play — ставится только файлом.
- Пока туннель поднят, Android показывает значок ключа в строке состояния.
  Это системное поведение, убрать его нельзя.
- Правила по доменам не покрывают случаи, когда сайт раздаёт разные адреса
  разным клиентам (крупные CDN) — подробности в [ROUTES.md](ROUTES.md).
