# QP VPN для iPhone

Приложение и расширение-туннель. Собирается, но поставить его на телефон
можно только через учётную запись разработчика Apple — это ограничение
самой Apple, обойти его нечем.

## Что уже сделано

| Часть | Файлы |
|---|---|
| Окно приложения | `QPVPN/ContentView.swift`, `AppModel.swift` |
| Системный VPN-профиль | `QPVPN/TunnelManager.swift` |
| Камера для QR-кода | `QPVPN/QRScannerView.swift` |
| Сам туннель | `QPVPNTunnel/PacketTunnelProvider.swift` |
| Маршруты, фильтры, подсети | `Shared/` |
| Разбор .conf с маскировкой | `Vendor/TunnelConfiguration+WgQuickConfig.swift` (MIT, из amneziawg-apple) |

Устройство то же, что на других платформах: главный фильтр «Обход
блокировок» на 244 сервиса, второй переключатель «Рабочие ресурсы»,
расширенные настройки с режимами и российской зоной. Маршруты считает
приложение и передаёт их расширению вместе с ключом; ключ лежит в связке
ключей телефона.

## Что нужно от владельца

1. **Учётная запись разработчика Apple** — Apple Developer Program,
   99 $ в год, оформляется на https://developer.apple.com/programs/
   (нужен Apple ID, номер телефона и карта; для компании ещё D-U-N-S).
2. После оформления — идентификатор команды (Team ID, десять символов).
   Его нужно подставить в `project.yml`, поле `DEVELOPMENT_TEAM`.
3. В кабинете разработчика создать два идентификатора приложения:
   - `kz.qpvpn` — с возможностью **Network Extensions**
   - `kz.qpvpn.tunnel` — тоже с **Network Extensions**
4. Выбрать способ раздачи:
   - **TestFlight** — до 10 000 человек по ссылке-приглашению, проверка
     Apple проходит за день-два, приложение живёт 90 дней и продлевается
     новой сборкой;
   - **App Store** — обычная публикация, дольше и строже;
   - **Ad Hoc** — до 100 устройств, каждое нужно вносить по номеру UDID.

Для VPN-приложения Apple дополнительно спрашивает, кому оно нужно и
какие данные собирает. Наше не собирает ничего: ни аккаунтов, ни
статистики, ни журналов на сервере.

## Сборка

```
brew install xcodegen go
cd ios && xcodegen generate
open QPVPN.xcodeproj
```

В облаке сборка идёт без подписи — она проверяет, что код собирается и
что расширение с списком подсетей попали внутрь приложения:
`.github/workflows/ios.yml`.

## Чем пользоваться, пока нет учётной записи

Бесплатным клиентом **DefaultVPN** из App Store: он принимает те же
ключи `vpn://` с AmneziaWG. Инструкция — в комплекте, папка `iPhone`.
