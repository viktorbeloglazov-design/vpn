# VPN на Windows — установка

Для Windows 10 (сборка 1709 и новее) и Windows 11, 64 бита.

Своего приложения QP VPN для Windows пока нет — на компьютере с Windows
используется бесплатный клиент **AmneziaVPN**. Ключ тот же самый: тот QR-код
или ссылка `vpn://…`, что и на телефоне.

---

## 1. Установить AmneziaVPN

1. Откройте страницу загрузки: **https://amnezia.org/ru/downloads**
   (в этой папке лежит ярлык **Скачать-AmneziaVPN.url** — он ведёт туда же,
   и картинка **QR-скачать-AmneziaVPN.png**, если удобнее с телефона).
2. Скачайте версию для Windows и запустите установщик.
3. Windows может показать синее окно **«Система Windows защитила ваш
   компьютер»** — нажмите **«Подробнее» → «Выполнить в любом случае»**.
4. Пройдите установку кнопкой «Далее». В конце разрешите установку
   сетевого драйвера, если система спросит, — без него туннель не работает.

---

## 2. Добавить ключ, который вам прислали

На компьютере удобнее всего вставить **ссылку** — это ровно то же самое,
что зашито в QR-код.

1. Скопируйте присланную ссылку вида `vpn://…` целиком.
2. Откройте AmneziaVPN.
3. Нажмите **«+»** сверху (или кнопку **«Начать»**, если подключений ещё нет).
4. Выберите пункт про ключ подключения и нажмите **«Вставить»**
   рядом с полем ввода — ссылка встанет из буфера обмена.
5. **«Продолжить» → «Подключиться»**.

### Если у вас только картинка с QR-кодом

В AmneziaVPN есть пункт со сканированием QR-кода камерой: откройте
**«+» → подключение по QR-коду** и покажите код в камеру ноутбука.
Если камеры нет — попросите прислать вам ссылку `vpn://…` текстом,
она равнозначна коду.

---

## 3. Проверить

1. Нажмите **«Подключиться»** — кнопка станет зелёной.
2. Откройте в браузере **https://2ip.ru** — страна должна быть Казахстан.

---

## 4. Настройка маршрутов (необязательно)

В AmneziaVPN есть раздел **«Разделение сайтов»** и **«Разделение
приложений»** — туда можно добавить сайты и программы, которые должны
идти мимо VPN (например, российские банки и госуслуги) или наоборот
только через VPN.

---

## Если что-то не так

| Что видно | Что делать |
|---|---|
| «Ключ недействителен» | Скопируйте ссылку ещё раз целиком, от `vpn://` до конца, без пробелов и переносов |
| Подключается и сразу отключается | Проверьте, что не запущен другой VPN; перезагрузите компьютер после установки драйвера |
| Интернет пропал при включении | Отключитесь, проверьте интернет без VPN; напишите нам |
| Страна не Казахстан | Отключитесь и подключитесь снова, затем обновите страницу проверки |
