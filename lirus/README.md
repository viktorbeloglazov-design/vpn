# LiRus — русский язык в Li Auto L9

Проект из двух этапов.

**Этап 1 (сейчас).** Выяснить, лежит ли в прошивке Li OS 8.6.0 готовый русский
перевод — и если да, то насколько полный. Только чтение: в машине ничего не
меняется, root не нужен, системные разделы не трогаются.

**Этап 2 (только если перевод найден).** Приложение «LiRus Switch» с двумя
кнопками — «Русский» и «English (откат)».

---

## Этап 1: проверка

### Что нужно

| Что | Зачем |
|---|---|
| Ноутбук с macOS или Linux | скрипт работает на обычном `bash` |
| Кабель USB → USB-C | порт в переднем подлокотнике L9 |
| Android Platform Tools | команда `adb` |
| Android SDK Build-Tools | программа `aapt2`, она читает ресурсы APK |

На Mac проще всего так:

```bash
brew install --cask android-platform-tools
brew install --cask android-commandlinetools
sdkmanager "build-tools;34.0.0"
```

### Отладка по USB в машине

Скрипту нужен доступ по `adb`. В Li OS отладка включается в инженерном меню
прошивки; если в вашей версии её там нет — этап 1 выполнить не получится, и
это сразу ответ: без `adb` ни проверить, ни переключить язык нельзя.

Проверка связи:

```bash
adb devices
```

В списке должна появиться строка с серийным номером и словом `device`.
Если написано `unauthorized` — на экране машины появится запрос, разрешите
подключение.

### Запуск

```bash
./lirus/scripts/check_ru.sh                 # ключевые и фирменные пакеты
./lirus/scripts/check_ru.sh --all           # вообще всё, что установлено (долго)
./lirus/scripts/check_ru.sh --out ~/ru.md   # куда положить отчёт
```

Скрипт читает сведения о системе, копирует установленные APK к себе во
временный каталог на ноутбуке и смотрит, есть ли внутри ресурсы `values-ru`.
Копии удаляются после разбора (ключ `--keep` их оставит).

Результат — файл `check_ru_report.md`:

- версия Android и сборки, текущие языки (`system_locales`, `persist.sys.locale`);
- таблица пакетов: есть ли русские ресурсы, сколько русских строк против
  базовых, какой процент переведён;
- вердикт: **ДА** (перевод есть и в рамке системы, и в интерфейсе),
  **ЧАСТИЧНО** (переведена только рамка Android), **НЕТ**.

### Чего ожидать

В китайских прошивках чаще всего сохраняется русский в рамке Android
(`framework-res`) — это системные диалоги, клавиатура, сообщения об ошибках, —
а фирменные экраны Li Auto (климат, приборка, камеры, медиа) переведены только
на китайский и английский. Тогда вердикт будет **ЧАСТИЧНО**, и переключение
языка даст смешанный интерфейс. Точный ответ даст отчёт на вашей машине.

### Что скрипт не делает

Не пишет в машину вообще ничего: ни `settings put`, ни `setprop`, ни установки
и удаления пакетов, ни монтирования разделов. Все команды — чтение:
`getprop`, `settings get`, `pm list packages`, `adb pull`.

## Этап 2: «LiRus Switch» — после отчёта

Начнётся, только если в отчёте найдётся русский в ключевых пакетах. Задумка:

- приложение на Kotlin с двумя большими кнопками — «Русский» и «English»;
- переключение через `CHANGE_CONFIGURATION` — это разрешение уровня
  `development`, его можно выдать по USB командой
  `pm grant <пакет> android.permission.CHANGE_CONFIGURATION`, без root;
  если способ не сработает, пробуются запасные, и в README попадёт тот,
  который реально сработал в машине;
- повтор после перезагрузки и после обновления прошивки, если система вернула
  язык обратно;
- проверка после переключения: открываются ли камеры и ключевые программы,
  и автоматический откат на английский, если что-то не так;
- откат отдельной командой по USB.

Сначала — отчёт.
