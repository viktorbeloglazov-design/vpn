# Панель L9 — плитки и виджеты для экрана Lixiang L9

Программа для системы Android в мультимедиа Lixiang L9 (первое поколение).
Свой экран с плитками: ярлыки программ (Яндекс Навигатор, Яндекс Музыка,
что угодно ещё), настоящие системные виджеты и приборы — спидометр, счётчик
поездки, часы, кнопки проигрывателя.

```
┌───────────────────────────────────────────────────────────────┐
│ Панель L9                           [+ Плитка] [Править] [⚙]  │
├─────────────────────┬───────────┬─────────────────────────────┤
│                     │   14:38   │  ♪ Кино — Группа крови      │
│        78           │  Пятница, │      ⏮    ⏸    ⏭            │
│       км/ч          │ 19 сент.  ├──────────────┬──────────────┤
│                     ├───────────┼──────────────┤   Поездка    │

├─────────────────────┼───────────┼──────────────┤ Средняя 61   │
```

## Какие бывают плитки

| Плитка | Что делает |
|---|---|
| **Программа** | Ярлык: значок и подпись, нажатие открывает программу. Любая установленная — Яндекс Навигатор, Яндекс Музыка, 2ГИС, браузер |
| **Виджет** | Настоящий системный виджет чужой программы. Панель работает «хозяином виджетов» — тем же, чем обычно служит домашний экран |
| **Спидометр** | Скорость по GPS крупными цифрами. Сервисы Google не нужны |
| **Поездка** | Путь, средняя и наибольшая скорость, время в движении. Обнуляется кнопкой |
| **Часы** | Время и дата |
| **Музыка** | Название трека и кнопки «назад», «пауза», «дальше» для того проигрывателя, который играет сейчас |
| **Набор программ** | Несколько значков в одной плитке; тот же набор показывает виджет для рабочего стола машины |

Плитки раскладываются по сетке: число столбцов и рядов задаётся в настройках
(от 2 до 8 столбцов). Плитку можно растянуть на 2–4 клетки в любую сторону.

## Как менять раскладку

1. Нажмите **Править** (или долгое нажатие на любую плитку).
2. Плитку **перетащите** пальцем — она встанет в ближайшую свободную клетку.
   Если место занято, плитка вернётся назад: ничего не потеряется.
3. Кнопки **Ш−/Ш+** меняют ширину, **В−/В+** — высоту.
4. Крестик убирает плитку. Системный виджет при этом возвращается системе.
5. **Готово** — выход из правки.

Кнопка **+ Плитка** открывает выбор из трёх вкладок: «Приборы»,
«Программы» (все установленные плюс известные, которых ещё нет)
и «Виджеты» (всё, что предлагают установленные программы).

## Набор программ одним переключателем

В настройках есть раздел **«Набор программ»**. Включаете переключатель —
и набор появляется сразу в двух местах:

1. **Плиткой на главном экране панели** — ряд значков в одной клетке.
2. **В системном виджете «Набор программ»**, который кладётся на штатный
   рабочий стол машины долгим нажатием по свободному месту — так же, как
   её собственные виджеты. Нажатие по значку открывает программу.

Состав набора — до шести программ, по умолчанию Яндекс Навигатор, Яндекс
Музыка и Яндекс Карты. Любую можно убрать и добавить свою кнопкой
«Добавить программу». Выключили переключатель — плитка исчезла, виджет
опустел, остальная раскладка не тронута.

Если прошивка Lixiang не принимает чужие виджеты на свой рабочий стол —
набор всё равно остаётся плиткой внутри панели, а саму панель можно сделать
домашним экраном (переключатель «Предлагать как домашний экран»).

## Русский язык

Прошивка Lixiang приезжает с китайской или английской системой, и названия
программ на плитках выглядят соответственно. Панель русифицирует всё, что
показывает сама:

- **Русские названия программ** — словарь китайских и английских подписей
  (设置 → Настройки, 音乐 → Музыка, File Manager → Файлы и так далее).
  Работает и на плитках, и в списке выбора программ.
- **Интерфейс всегда по-русски** — панель не зависит от языка системы машины:
  свои строки, даты и системные сообщения она показывает по-русски.
- **Своя подпись у любой плитки** — «Править» → кнопка **Аа** на плитке →
  впишите нужное название. Оно сохраняется и не зависит от словаря.

Оба переключателя — в настройках, раздел «Язык», по умолчанию включены.

Чего программа не может: переписать меню самой машины. Штатные экраны
Lixiang, климат, настройки автомобиля рисует прошивка — сторонняя программа
в них не лезет. Русифицируется только панель и подписи на её плитках.

## Установка в машину

APK лежит в релизах репозитория (тег `panel-v*`), файл `PanelL9-*.apk`.

1. Скачайте файл на флешку или в память машины.
2. Откройте его проводником мультимедиа и разрешите установку из этого
   источника, когда система спросит.
3. Программа появится в списке приложений под именем **Панель L9**.

Если проводник в машине не даёт ставить файлы, тот же APK ставится по ADB
с ноутбука: `adb install PanelL9-1.0.0.apk`. Порт USB в переднем подлокотнике,
отладку по USB нужно включить в инженерных настройках прошивки.

Обновление ставится поверх: подпись одна и та же, раскладка плиток
сохраняется.

## Разрешения

| Разрешение | Зачем | Где выдать |
|---|---|---|
| Местоположение | Спидометр и счётчик поездки | Настройки панели → «Запросить» |
| Доступ к уведомлениям | Кнопки проигрывателя: система только с ним отдаёт управление чужой музыкой | Настройки панели → «Открыть настройки» |

Без этих разрешений панель работает — просто соответствующие плитки
показывают подсказку вместо цифр.

## Домашний экран

В настройках есть переключатель **«Предлагать как домашний экран»**. После
включения система начнёт спрашивать, чем открывать кнопку «домой», и панель
можно выбрать постоянным ответом. Прошивка Lixiang может этого не позволить —
тогда панель остаётся обычной программой, которую открывают значком.

## Чего панель не делает

- Не лезет в шину автомобиля: скорость берётся у GPS, а не у штатных
  датчиков. На стоянке и в тоннеле показания замирают — это видно по надписи
  «ищу спутники».
- Не подменяет штатный экран Lixiang и не трогает системные настройки машины.
- Не показывает виджеты поверх других программ: это отдельный экран, а не
  плавающее окно.

## Сборка

```bash
cd carpanel
gradle test            # разбор раскладки и расчёт скорости проверяются тестами
gradle assembleRelease # carpanel/app/build/outputs/apk/release/app-release.apk
```

Нужны JDK 17 и Android SDK 35. То же самое делает ветка сборки
`.github/workflows/carpanel.yml`: тесты, APK, проверка манифеста и выкладка
в релиз по ручному запуску.

Ключ подписи `carpanel/app/carpanel-sideload.jks` лежит в репозитории
осознанно — программа ставится файлом, а не через магазин, и ключ нужен
лишь для того, чтобы обновление вставало поверх прошлой версии.
